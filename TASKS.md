# Tasks

Use [GitHub issues](https://github.com/bernardopg/bitter-browser/issues) as the source of truth for current work. Before starting a substantial change, search for an existing issue and discuss the approach there. Do not interpret the original prompt as a completed roadmap.

Suggested areas for future issues: replace placeholder crates with implemented functionality; expand meaningful test coverage; test GUI and Flatpak behavior; improve documentation as features mature. These are suggestions, not commitments or scheduled milestones.
