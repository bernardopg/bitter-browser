Streaming responses

Receive results as they are produced instead of waiting for the whole response. Streams use server-sent events and resume where they left off.

Stablev4 API~3 min
RustPythoncurl
let client = Client::new("nw_live_…");
let mut stream = client.events().stream("orders").await?;

while let Some(event) = stream.next().await {
    // Each event arrives as soon as it is committed.
    println!("{} {}", event.kind, event.id);
}
✓ Streams reconnect with the last event ID, so a dropped connection never loses data.
