# Code of conduct

Be respectful and constructive. Harassment, discrimination, threats, personal attacks, disclosure of private information, and unwanted sexual attention are unacceptable. Discuss ideas and behavior rather than attacking people. Maintainers may remove content, close discussions or restrict participation to protect the community.

Report conduct concerns privately to a repository maintainer using GitHub's private communication mechanisms. Do not post sensitive personal information publicly. Maintainers will handle reports as discreetly as practical; no particular response time is guaranteed.
