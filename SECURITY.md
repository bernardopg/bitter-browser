# Security policy

Bitter Browser is experimental. The latest release is the only version intended to receive security fixes; older releases are not maintained. Do not use it for sensitive browsing without independently evaluating its security.

Please use [GitHub private vulnerability reporting](https://github.com/bernardopg/bitter-browser/security/advisories/new) to report suspected vulnerabilities. Include affected versions, reproduction steps, impact and any proposed mitigation. Do not disclose exploit details in a public issue before maintainers can investigate. There is no guaranteed response or fix timeline.

The [browser threat model](docs/threat-model.md) records trust boundaries,
current controls and outstanding release checks.
