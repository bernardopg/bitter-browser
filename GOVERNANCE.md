# Governance

The repository owner and maintainers with write access make project and release decisions. Contributions are reviewed for correctness, safety, maintainability and fit. Maintainers may request changes or decline a proposal, explaining the reason where practical. For larger changes, start with an issue so contributors can discuss scope before implementation.

There is currently no formal steering committee, voting process, response-time guarantee, or paid support. The owner can grant or revoke repository access. Security decisions follow [SECURITY.md](SECURITY.md). Community conduct follows [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
