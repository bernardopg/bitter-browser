Bitter Browser - portable Linux build
=====================================

Install for your user (no root needed):

    ./install.sh

Install for every user:

    sudo ./install.sh

Remove it again with the same command plus --uninstall.

Requirements: x86-64 Linux with glibc 2.41 or newer, GTK 4.14+, libadwaita
1.6+ and WebKitGTK 6.0 (2.44+). Debian 13, Ubuntu 25.10, Fedora 42, Arch
Linux and openSUSE Tumbleweed or newer have them. install.sh names any
missing library and the package that provides it.

Run without installing:  ./bin/bitter-ui
